# Focus group meeting 2026-09-24 — confirmed decisions

**Source:** maintainer's confirmation on 2026-09-29 of decisions approved in the Teams
focus group meeting on 2026-09-24. This is a partial record, expanded as outcomes are confirmed.

## COSI naming — ADR-000020

The focus group approved:

- **COSI — Corrugated Standard Interface** as the standard's name.
- **`cosi:<x>:1.0`** as the schema identifier scheme.
- **VDW** remaining the publishing association.

## Numeric precision

The focus group approved numeric precision according to the data type, with no assumptions
about fixed decimal places and no additional precision restrictions or limits imposed by COSI.
Producers send the precision their source data type provides.

## Closed fault-code list — ADR-000015

The focus group approved:

- `faultCode` is a closed list enforced by an enum in the schema: the 40 listed codes plus `null`.
- Vendors may optionally publish `internalCode`.
- Every new entry in the fault-code list requires a new version of the standard.

## Communication directions — ADR-000010

The focus group approved:

- OT comprises Levels 0–3; IT comprises Levels 4–5.
- IT↔OT communication goes through the Level 3.5 MQTT broker.
- Direct IT↔OT crossings are prohibited in both directions.
- Cloud services remain optional.

## Acceptance of three ADRs

The focus group approved moving these records from Proposed to Accepted:

- ADR-000003: dedicated infeed settings in setup-converting.
- ADR-000005: remove actuals and feedback data from setup messages.
- ADR-000006: setup responses using `OK` / `NOK`, with correlation through the envelope.

## Common types approval

The focus group explicitly approved `common-types.schema.json`, containing the shared quantity
types and `customProps` definition.

## Die-pressure consolidation — ADR-000009

The focus group approved the optional top-level `diePressure` quantity in the performance
payload for flat-bed die cutters: `{ "value": <number>, "uom": "kN" }`, with the unit fixed
to `kN`. This confirms the replacement of the redundant triple nesting by a single quantity.

## Queue reference field name

The focus group selected **`setupRef`** to comply with the cross-system reference naming
convention. Documentation must explain that this reference is commonly known as **setupId**.
The JSON field name is `setupRef`; `setupId` is not a wire-format alias.

## Target-speed baseline

The target-speed baseline is supplied by ERP/MES according to the plant's business rules.
Its derivation can differ between implementations. COSI does not prescribe a common calculation
method or require local best performance, a cross-site benchmark or a theoretical model.
